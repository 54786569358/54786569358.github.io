## 起因

博客这个东西，我大概建过三四次，每次都是同一个结局：装了个很重的系统，改了一堆主题，写了两篇文章，然后某天服务器到期，就再也没开过。

这次换个思路——**越轻越好**。

## 这次的技术选择

| 环节 | 方案 | 理由 |
|---|---|---|
| 写作 | Markdown 文件 | 纯文本，二十年后还打得开 |
| 生成 | Hugo | 单个可执行文件，构建不到 1 秒 |
| 托管 | GitHub Pages | 免费，不用管服务器 |
| 部署 | GitHub Actions | `git push` 即上线 |
| 评论 | giscus | 基于 GitHub Discussions，不需要数据库 |

整个站点的构建产物只有几百 KB，没有数据库，没有后台，没有需要夜里三点起来修的东西。

## 接下来

大概会写这几类东西：

1. 折腾电脑的笔记（比如这次把一台 Windows 配成远程可控机器）
2. 读到的东西
3. 偶尔的生活记录

更新频率不敢保证，但至少不会因为「服务器挂了」而停更了。
