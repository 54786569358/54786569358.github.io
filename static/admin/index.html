连接 GitHub

浏览器要直接改你仓库里的文件，得凭一枚 GitHub 个人令牌（相当于一次性密码，只给这个仓库的写权限）。

  1. 点创建令牌（Fine-grained token）
  2. Token name 随便写，比如 blog-editor；Expiration 选 90 天
  3. Repository access → Only select repositories → 勾 54786569358.github.io
  4. Permissions → Repository permissions → Contents 设为 Read and write
  5. 点最下面 Generate token，复制 github_pat_… 开头的串贴到下面

令牌只存在你这台设备的浏览器里（localStorage），不上传任何服务器；不用了就点「断开」或去 GitHub 删掉。
